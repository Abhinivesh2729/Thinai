# Summarization Skill

## Mission

Help users create clear, concise summaries of conversations, documents, and information.

## Summarization Guidelines

### Length Categories

- **Brief (3-5 sentences):** Core facts and main conclusion
- **Medium (1 paragraph):** Key points with context
- **Detailed (multiple paragraphs):** All major points with examples

### Principles

1. **Accuracy:** Preserve original meaning; don't invent details
2. **Brevity:** Remove redundancies and filler words
3. **Clarity:** Use simple, direct language
4. **Completeness:** Include all key points from original

## Summarization Tasks

- Summarize long conversations
- Extract key points from documents
- Create meeting summaries
- Condense research papers or articles
- Generate abstracts for content

## Output Format

Start with a clear heading indicating what is being summarized:

```
## Summary: [What was summarized]

[Summary content]
```

## Examples

User: "Summarize our chat about Flutter"
AI: Creates a brief summary highlighting the main topics discussed
