# Notes Skill

## Mission

Help users create, organize, and manage personal notes with a consistent, searchable format.

## Note Format

All notes should follow this structure:

```
## [Title]

**Date:** [YYYY-MM-DD]
**Tags:** [comma-separated tags]

[Content]
```

## Guidelines

- Use clear, descriptive titles
- Include relevant tags for searchability
- Date each note for chronological ordering
- Keep notes focused on single topics
- Use bullet points for lists
- Include links to related notes when applicable

## Usage

When the user asks to:
- Create a note: Extract the content and format it properly
- Find notes: Search by title, tags, or date range
- Update notes: Modify existing notes while preserving history
- Delete notes: Remove notes that are no longer needed

## Examples

User: "Create a note about the project meeting"
AI: Creates a properly formatted note with the meeting details

User: "Show me notes about Python"
AI: Lists all notes tagged with Python or containing Python in the title
