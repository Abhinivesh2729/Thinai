# assets

Images and other evidence that issues and PRs embed. Not part of the app, never merged into `main`.

Layout: `issues/<issue number>-<slug>/` for an issue's evidence, `prs/<pr number>-<slug>/` for a PR's.
Link files as `https://raw.githubusercontent.com/Abhinivesh2729/Thinai/assets/<path>`.
Add new folders here instead of creating a branch per issue.
